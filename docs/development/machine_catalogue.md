# Native machine and boundary catalogue

Current owner index for the complete audited process, generator, consumer, reactor and transport scope. Numeric contracts live in the current references; linked native source and loaded recipes specify exact behavior. Internal aliases are included for contributor search, not player naming. The source catalogue does not assert runtime obtainability or physical calibration for every registered machine.
